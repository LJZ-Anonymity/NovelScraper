# 《末世为王》（天地一瞬）小说 EPUB 下载

## 📖 项目简介

由于网上难以找到《末世为王》的完整小说下载，本项目通过编写爬虫脚本从笔趣阁抓取，并与[书旗网](https://t.shuqi.com/book/7720177)的版本进行了校对，最终整理为 EPUB 格式，方便在各类阅读器上阅读。

## ✨ 特性

- **校对版**：修复了笔趣阁原站的大量章节错误。
- **EPUB 格式**：解压即用，适配大多数电子书阅读器。
- **开源脚本**：爬虫脚本已开源，可供学习参考。

## 📥 下载

请前往 [Releases](https://github.com/LZ-Anonymity/NovelScraper/releases) 页面下载最新的 `末世为王.zip`，解压后即可获得 EPUB 文件。
